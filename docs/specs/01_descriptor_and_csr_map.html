SPEC-01

Descriptor Format and Register Map Summary

32-byte descriptor layout, flags, status write-back, chain rules, CSR map summary

Verification engineer handout
Document: SPEC-01Revision: 1.0Date: 13 Nov 2026

1What a descriptor is

A descriptor is a 32-byte record that software writes into memory. It tells the DMA one job: "copy LENGTH bytes from SRC to DST". Each descriptor also holds the address of the next descriptor, so several jobs form a chain (a linked list). Software writes the address of the first descriptor into the CSR NEXT_DESC register and sets RUN; the descriptor engine then walks the chain on its own.

After finishing a descriptor, the hardware writes a status word back into the descriptor and clears its OWNED flag, so software can see which jobs are done.

Spec IDRequirement (the design SHALL ...)
DESC-FMT-001A descriptor is 32 bytes, 32-byte aligned. The hardware ignores bits [4:0] of every descriptor pointer (CSR NEXT_DESC and the NEXT_DESC word) and uses pointer & 0xFFFF_FFE0.
DESC-FMT-002Word layout as in Table 1-2; multi-byte values are little-endian.
DESC-FLG-001A descriptor is processed only if OWNED = 1. This check is made for every descriptor of the chain, the first one included.
DESC-FLG-002INC_SRC / INC_DST select incrementing (1) or fixed (0) addressing of the source / destination engine.
DESC-FLG-003GEN_SOP / GEN_EOP are passed to the engines; they control packet framing in M2S mode.
DESC-WB-001After a processed descriptor the hardware writes the STATUS word (Table 1-4) to offset 0x10, then writes CTRL back to offset 0x08 with OWNED = 0 and all other CTRL bits unchanged.
DESC-WB-002STATUS.BYTES is the destination engine's bytes_done; STATUS.ERR is the OR of both engines' err; STATUS.EOP is the OR of both engines' eop_seen.
DESC-WB-003The hardware never writes SRC_ADDR, DST_ADDR, NEXT_DESC or the reserved words.
DESC-CHN-001The chain ends (CSR DONE) after a descriptor whose NEXT_DESC is 0, or when a descriptor with OWNED = 0 is fetched (that descriptor is not written back). Errors end the chain with CSR ERROR (SPEC-05).
Software must not change a descriptor while the DMA is busy, and must set OWNED = 1 in every descriptor it wants processed.
