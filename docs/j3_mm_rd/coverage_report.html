1How to fill this report

  • One row per coverpoint or cross of your test plan's coverage table.
  • Achieved is the merged result of the whole regression, not of a single seed.
  • For every coverpoint below its goal list the holes (bins not hit) and either the test that closes them or a justification (for example: unreachable by design, illegal by spec, agreed with the reviewer).
  • Rows in grey italics are examples; replace them.
Collecting the numbers: let your coverage collector print, in its report_phase, the coverage of each coverpoint (cg.cp.get_coverage() / get_inst_coverage()). To merge seeds use your simulator's merge tool (VCS urg, Questa vcover merge, Xcelium imc). If your simulator does not support covergroups, implement the same bins as counters in the collector, write the hit counts to a file per run and add them up.
