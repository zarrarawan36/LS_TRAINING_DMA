bug_reports/  -  one report per confirmed design issue
=====================================================================

Before filing: re-read the spec ID and make sure the testbench is right
(expected value, timing, configuration).

Fill in docs/j3_mm_rd/bug_report.html and Export; save the export here.
Every report gives: spec ID, test name, seed, expected vs. actual,
simulation time of the first wrong value.

Next to the report keep the failing log (copy of
sim/logs/<test>_<seed>.log) and put waveform screenshots into diagrams/
(see diagrams/README.txt).
